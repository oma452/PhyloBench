# Changelog

## [0.1.0] - 2026-11-20

Initial release of PhyloBench, including:

- rooted-tree validation and traversal;
- binary-lifting lowest common ancestor queries;
- duplication-loss reconciliation;
- deterministic gene-family simulation with explicit resource limits;
- evaluation metrics and experiment reporting;
- visualization, provenance manifests, and artifact hashes; and
- automated tests and reproducibility tooling.
